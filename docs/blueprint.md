# **App Name**: LimaStream

## Core Features:

- Title Search: Allow users to search for movies and series by title.
- Genre Filtering: Enable users to filter content by genre (Drama, Comedy, Action, Sci-Fi).
- Content Display: Display search results and featured content in a grid layout.
- Title Details: Show detailed information about each title, including synopsis, rating, and comments.
- User Authentication: Allow users to create accounts, log in, and log out.
- Content Rating: Allow logged-in users to rate titles and save their ratings.
- User Commenting: Enable logged-in users to post comments on title pages.

## Style Guidelines:

- Primary color: Deep, vibrant orange (#FF8C00), reminiscent of the energy and warmth of a cinema screen.
- Background color: Dark navy blue (#0A192F), providing a cinematic and immersive backdrop.
- Accent color: Electric blue (#7DF9FF) to highlight interactive elements and calls to action.
- Headline font: 'Poppins', a sans-serif font, for titles and headings, ensuring clarity and modern appeal.
- Body font: 'PT Sans', a versatile sans-serif font, for descriptions and body text, enhancing readability.
- Use clean, minimalist icons for navigation and user actions.
- Implement subtle transition animations when navigating between pages and displaying content.
